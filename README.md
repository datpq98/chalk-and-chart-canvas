# Chalk And Chart Canvas

tôi muốn build 1 app bảng trắng bằng canvas, trên đó có widget bảng biểu, có thể kéo thả, bảng này có thể thêm sửa xóa các cột nhưng excel, có nút chuyển thành biểu đồ, bấm vào sẽ có popup chọn tất cả các loại biểu đồ hiện có. Sau khi bấm xong thì sẽ sẽ có hình biểu đồ xuất hiện bên cạnh, có thể sửa data trên bảng và biểu đồ sẽ được cập nhật tức thời. Tôi cần 1 UI đẹp để phục vụ cho việc dạy học
